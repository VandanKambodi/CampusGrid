# 🎓 CampusGrid - Smart Campus Operating System

> **The entire campus. In your pocket.**
>
> CampusGrid is a centralized, authenticated full-stack campus networking platform built to eliminate chaotic messaging groups. It empowers students and administrators to seamlessly share verified academic notes, recover lost essentials, discover placements, and build a digital engineering legacy.

---

## ✨ Key Features

* **🔐 Institutional Authentication:** Strict Roll Number-based access. Includes an interactive request system for account creation and password resets, managed entirely by admins.
* **📚 Resource Vault:** A peer-reviewed hub to upload, upvote, and directly read study notes, previous year question papers, and lab manuals natively in the browser.
* **💼 Placements Cell:** An admin-curated board for verified internships, hackathons, and full-time roles to protect students from unverified listings.
* **🔍 Lost & Found Hub:** Image-supported tracking threads to quickly recover misplaced items on campus.
* **📢 Announcements & Student Blogs:** A dynamic, centralized feed for official administrative updates and peer knowledge sharing, complete with likes and nested comments.
* **🤝 Campus Network (Directory):** Discover batchmates, view their tech stacks, explore their GitHub portfolios, and build connections via the Follow/Unfollow system.
* **🛡️ Admin Command Center:** A powerful, protected dashboard for administrators to approve/reject onboarding requests, manually register users, and override passwords.
* **🌗 Modern UI/UX:** A fully responsive, glassmorphic design featuring strict geometric layouts and seamless Dark/Light mode toggling.

---

## 🛠️ Tech Stack

### **Frontend (Client)**

* **Framework:** React.js (Vite)
* **Styling:** Tailwind CSS (with native Dark Mode support)
* **Routing:** React Router DOM
* **Icons:** Lucide React
* **HTTP Client:** Axios

### **Backend (Server)**

* **Runtime:** Node.js
* **Framework:** Express.js
* **Database:** MongoDB & Mongoose
* **Authentication:** JSON Web Tokens (JWT) & Bcrypt.js
* **Storage:** Cloudinary (Images & RAW PDF Document delivery) & Multer
